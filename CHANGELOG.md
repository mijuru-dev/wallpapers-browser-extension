# Changelog

User-facing changes in Mijuru Wallpapers. Store updates may appear a few days after a release.

## 1.4.0
- Shortcuts on the New Tab: Mijuru wallpapers and our wallpaper apps for Android and PC, plus room for your own sites.
- Keep them in a column on the left or in a row under search.
- A Settings button on the New Tab: show or hide the clock, greeting, search, wallpaper name and buttons.

## 1.3.0
- A wider window: wallpapers are twice as large, still one per row.
- Like, add to collection, set as New Tab background or download right from each wallpaper.
- Favorites are now your Collection. One switch rotates your New Tab wallpapers from it.
- Random is now an endless feed of random wallpapers.
- Only 16:9 4K wallpapers, so every one fits a widescreen monitor.

## 1.2.0
- Set a wallpaper from mijuru.com in one click: press "Set as New Tab wallpaper" on any desktop wallpaper page.
- Picked a wallpaper on the site before installing? It is set right after install.

*Opera: the button is called "Set as Mijuru tab wallpaper".*

## 1.1.0
- After you install the extension, a short welcome page shows how it works and where else you can get Mijuru wallpapers.
- If you remove the extension, a page with a one-question survey asks what went wrong, so we can fix it.

## 1.0.0
- Sharper New Tab background: the full-size wallpaper that fits your screen (up to 4K and beyond) instead of a preview. If it cannot be loaded, the preview is shown, so the page never stays empty.
- New name in the store: Mijuru: 4K New Tab Wallpapers & Backgrounds.
- Light theme: the wallpaper title on the main screen is readable again.

*Opera: the sharper background appears on the Mijuru tab.*
